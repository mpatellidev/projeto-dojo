# Previsão de preços de imóveis

Projeto didático de análise de dados e regressão com um fluxo simples para iniciantes.
O modelo final alcançou R² de 0,716 nos dados de teste.

## Como executar

1. Instale as bibliotecas com `pip install -r requirements.txt`.
2. Abra a pasta `notebook` no Jupyter.
3. Execute `tratamento.ipynb`, `EDA.ipynb` e `machine-learning.ipynb`, nessa ordem.

## Bibliotecas

O projeto usa `pandas`, `matplotlib`, `seaborn`, `scikit-learn` e `jupyter`.
Consulte [DOCUMENTACAO.md](DOCUMENTACAO.md) para entender as etapas e as métricas.
